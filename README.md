# PanaHome

AI-Powered AR Real Estate Platform with 6-Photo Virtual Walkthrough and Furniture Placement

## Tech Stack
- React Native (Expo)
- TypeScript
- ViroReact (AR)
- NativeWind (Tailwind CSS)
- Supabase
- OpenCV.js (Blur Detection)
- Google Vision API (Fake Image Detection)
- scikit-learn (Price Recommendation)

## Setup
```bash
npm install
npx expo start
```
